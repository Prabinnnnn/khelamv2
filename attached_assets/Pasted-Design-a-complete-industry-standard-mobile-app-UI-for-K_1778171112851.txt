Design a complete, industry-standard mobile app UI for "Khelam" using react native— a sports and gaming matchmaking platform where users can discover, join, and host games (futsal, football, cricket, esports, etc.) within their city.

The design must be:

User-friendly, intuitive, and scalable

Cross-platform (iOS + Android)

Dark-themed, energetic, and premium

Inspired by a fusion of GoodRec + Strava + Partiful

🎯 CORE USER FLOWS

Entry & Authentication Flow
First-time user:

Open app → Welcome screen

Options: Log In / Sign Up

Sign Up via Email or Phone → OTP verification

After OTP verification → user is logged in

First login → City Selection → Sport Selection → Discover

Returning user:

Open app → Directly land on Discover screen

Guest mode:

Not allowed

Game Discovery Flow
Discover shows only selected sport games

Sorted by nearest upcoming time

Always filtered by selected city

Filters:

Date → single select

Time of day → multi-select

Spots available → single select

Game states:

Full → visible + disabled Join + "Full" badge

Locked (<1 hour) → visible + disabled Join + "Locked" badge

Join Game + Payment Flow
Tap “Join Game” → opens confirmation screen

Then proceed to payment

Slot handling:

No reservation system

First successful payment confirms slot

Payment outcomes:

Success → return to Game Details (joined state updated)

Failure → return to Game Details + error feedback

Cancellation:

Allowed until 24 hours before game

Refund → wallet credit

Hosting Flow
Host Verification:

ID upload + manual approval

States: Not Applied → Pending → Verified

Create Game:

Single scrollable form

Editing Rules:

If no players joined → fully editable

If players joined:

Cannot edit: time, venue, price, slots

Can edit: rules, notes

Cancellation:

Allowed anytime (must provide reason)

Players receive:

Full refund (wallet)

Notification

Host permissions:

Can view joined players list

Cannot approve/reject players

No chat (MVP)

Notifications
Trigger events:

Game joined confirmation

Game reminders

Host cancels game

Host verification updates

Timing:

24 hours before + 1 hour before

Channel:

In-app notifications only

Behavior:

Tapping notification opens relevant screen (deep linking)

Edge Cases & UX States
Include for ALL screens:

Loading → skeleton UI

Empty → illustration + helpful message

Error → retry option

Disabled → clear visual state

Critical edge cases:

Game becomes full while joining → show error

Payment failure → clear feedback

Network failure → toast + retry
